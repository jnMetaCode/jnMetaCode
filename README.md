#### 🛠️ local-agent-toolkit · 本地三件套（一条命令就能用，无需安装）

> agent 最缺的三样东西，每样一个小工具，零依赖、数据不出本机：

| 工具 | 解决什么问题 | 试一下 |
|---|---|---|
| 🧠 [engram](https://github.com/jnMetaCode/engram) | **记忆**：让 AI 记住你的笔记和决定，问它能带出处回答，而且越用越准 | `npx @jnmetacode/engram ingest ~/notes` |
| 🍳 [skillet](https://github.com/jnMetaCode/skillet) | **技能**：像 npm 一样给 agent 装技能，一条命令搞定（[在线技能库](https://jnmetacode.github.io/skillet/)） | `npx @jnmetacode/skillet add pdf` |
| 🔭 [tracelet](https://github.com/jnMetaCode/tracelet) | **眼睛**：实时看到 AI 每一步干了啥、花了多少钱，像浏览器的 Network 面板 | `npx @jnmetacode/tracelet` |

在 Claude Code 里一条命令全装：`/plugin marketplace add jnMetaCode/local-agent-toolkit`
